BEFORE YOU INSTALL

Compatibility

Understand what the installer can change and what varies by Linux distribution.

◈

Plymouth

Primary splash renderer

Plymouth displays the graphical splash from early userspace toward the display manager. The exported theme uses its script plugin and raster assets.

⌘

GRUB

Bootloader settings

GRUB can pass quiet splash to the kernel and optionally show its own themed menu. This editor targets the post-bootloader Plymouth splash.

◫

Initramfs

Required integration

The active initramfs must include Plymouth and the selected theme. Supported rebuild tools are update-initramfs, dracut, and mkinitcpio.

▤

Graphics stack

Hardware dependent

Early graphics generally relies on kernel mode-setting (KMS) or a usable framebuffer. Some drivers and firmware still show text or brief mode switches.

!
No tool can guarantee a completely text-free boot on every machine.

Firmware messages, bootloader output, kernel warnings, disk-encryption prompts, and the display manager handoff may still appear. Keep a recovery path and test after installation.
